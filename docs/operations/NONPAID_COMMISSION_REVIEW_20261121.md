# 非实付历史价差的佣金收件处理

请求冻结售价和 OPS 实扣不一致时，保留两项原始凭据。仅当资金分配全部为非实付且没有欠款，记录实际消费及余额顺序，佣金为零，以 nonpaid_price_difference_review 留下核对原因和冻结报价。禁止修改原报价、重复扣用户钱包或生成佣金。实付、混合资金及欠款价差仍进入人工核对。

本地验证：完整 service/opswallet 通过；另用新编译测试程序在 SQLite、MySQL 8.4.6 和 PostgreSQL 16.16 完成 8 组 × 3 数据库共 24 项，无跳过。覆盖价差留痕、同用户队列顺序、跨用户隔离、重放幂等、部分退款、资金来源、冻结报价、提现及期初来源。隔离库已清理。没有新增表或索引。

发布继续遵守 AGENTS.md 可用性要求：不可暂停用户调用；已提交产物先验证零流量候选、静态资源、OPS 索引依赖与费用读取，随后逐步蓝绿切流。代码通过不代表线上积压已经处理，生产复核另行记录。
