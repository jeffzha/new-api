# 自动检测模板

检测模板是一份不含密钥的最小测试请求，记录接口、公开测试内容、输出上限、超时、结果校验和费用上限。模板使用执行器环境变量引用专用平台 Key，经平台正常鉴权、指定渠道和计费链路调用。

## 生成和维护

- 在模型健康的全局规则中配置自动模板策略：专用监测令牌 ID、执行器密钥环境变量引用、单次费用上限并启用。GET/PUT `/api/model-health/auto-templates` 要求模型健康规则管理权限，修改进入既有审计。
- Gateway 启动和之后每 30 秒根据渠道目录补齐模板；读取计划时也能立即生成默认值。不会因补模板而发起检测或启用定时规则。
- 自动模板跟随渠道地址、模型映射及端点变化；管理员保存单模型模板后，该模板归管理员维护，自动同步不覆盖。其渠道绑定改变后需要重新确认。
- 禁用自动策略会停止自动生成和更新，已保存模板仍保留。定时检测需要单独管理。
- 专用令牌模型白名单自动扩展到有效渠道模型；不更改令牌有效期、额度、状态，不重新启用撤销的令牌，也不清空可能包含未入库扣费的 Redis 额度缓存。

## 默认支持范围

标准文本协议支持 OpenAI Chat、Anthropic Messages、Responses、Gemini；已知维度的向量模型和标准 Jina 兼容重排序也生成已确认模板。文本默认 128 输出 Token、非流式，GLM 和 DeepSeek v4 使用 low reasoning effort。具体供应商仍可能需要单独适配。

原生 OpenAI Seedance 渠道（1000）中有明确平台标价的模型，使用 4 秒、720p、16:9、不生成音频、不带参考视频的检测规格；预留金额按平台公开模型的价格估算，加 25% 余量并向上取整到元。费用上限仍受全局检测预算约束。模型映射名不参与平台价格查找。生成只提交一次，查询原任务，成功后通过平台的任务内容接口下载并校验 MP4，不依赖供应商返回 metadata.url。

其他视频、图片、TTS、语音识别及音频生成保留可编辑草稿，页面显示待确认原因。尺寸、时长、音色、测试音频、响应字段和价格上限不能跨供应商猜测，因此草稿不允许直接提交收费检测。未知向量维度同样需要确认。新出现的不受支持端点也保留草稿，不能把草稿数量当作已检测成功数量。

## 检测预算与跨天排期

- 检测周期设置内提供 GET/PUT `/api/model-health/cycle-budget`，使用既有规则管理权限和操作审计；支持整体、类型以及渠道/模型/端点范围。金额以人民币显示和输入，接口用整数微元保存。
- 预算继承优先级为模型 > 类型 > 整体；所有范围额外受整体总预算和单次上限约束，不能通过模型覆盖绕开整体总额。类型预算统计本类型目标，模型预算统计当前渠道/模型/端点，整体统计全部检测。
- 整体默认推荐每 7 天 200 元，单次最多 5 元；可设置 1 至 7 整天预算周期，不再要求月预算。检测频率与预算周期分别设置，类型和模型未单独设置时继承。保存整体周期预算后替代旧日/月金额限制，原并发与渠道限速继续生效；未保存前继续执行原限制，GET 不自动放大预算。
- 类型/模型推荐金额按已确认模板预留上限、检测频率及周期内次数计算，另加 20% 余量并向上取整到元；单次推荐最多 5 元。不自动保存推荐值。缺模板的目标明确提示，预估不是实际扣款或全部模型已覆盖的承诺。
- 页面显示实际生效来源、周期起止、已用及预留、待核实费用、范围和整体剩余；达到 80%、估算覆盖不足、整体余量低于单次上限、缺少模板或单次超限时持续提示。预算不足只延后新检测，不自动加款，不影响客户 API。
- 金额调整不重置已用额度；预算周期长度修改在当前边界后生效；未核实费用预留跨周期保留，确认费用后按其原检测周期归属核销。入队及提交前都在跨实例串行事务内检查，提交前排除自身预留，避免重复计算。
- HTTP 服务每 30 秒有界扫描最多 25 条终态检测，通过请求号、渠道、公开模型、检测专用令牌和已结算 CNY 账单核销内部费用预留。核销采用同一检测事务内 CAS，重复执行不重复记账，不操作客户钱包，也不冒充 OPS 费用回执。
- 视频提交日志可能只是预扣。原生视频需核对任务身份和最终结算回执，以实际提交的钱包额度和冻结换算信息计入检测预算。缺账单、未完成结算、失败但费用不明的记录继续保留预留，不自动记零。
- 图片和视频首次到期时间持久保存；当天因预算或并发上限未发出，跨天仍保持到期，不重新推迟七天。已发出的任务继续查询同一任务，不重复提交。
- 待执行媒体按原始到期时间排序，优先补测更早到期的目标；尚未发出即被跳过的任务不占用已检测周期或每日次数。
- 七天周期表示重复检测间隔，不等于所有模型都已覆盖。单次超限、模板未确认、总预算不足、上游异常及账单未核实都可能妨碍覆盖；必须明确处理这些阻塞，不能把跳过算作检测完成。
- 自动生成模板不修改已有定时开关；已启用的七天规则在模板及预算就绪后会执行。提高预算是独立的管理员配置操作，发布代码不自动提高预算。

## 执行和发布

平台模式执行器使用 `platform-target-v2` 就绪绑定，绑定到渠道、模型、端点及模板版本，避免同上游未配置模型阻塞其他模型，或继承其他模型的就绪状态。兼容读取旧执行器的直接上游绑定。

先升级 Gateway HTTP 池，再升级独立执行器，最后启用自动策略。保持现有用户 API、流和异步任务运行，不重载 Caddy。先完成隔离本地联调，再验证无流量候选及静态资源，通过私有 DNS 逐步切流。监测执行器换版先确认无在途检测；不得重提已付费任务。

本变更不新增表或索引，模板扩展字段存放在既有 `model_health_configs` JSON 中。发布仍须执行既有主库及依赖 OPS 索引就绪门禁。
